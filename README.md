# Pesca Tarocchi

Pesca Tarocchi è una Web App pensata durante un dialogo, sui medesimi, tra amici, portata in vita e sviluppata con Next.js. Un viaggio simbolico attraverso diverse attività quali: Carta del giorno, Ruota dell'anno e Stesa a tre carte.

Per provare la web app, ecco l'url: https://pesca-tarocchi-ag.vercel.app/


### 🎯 Obiettivi

- Offrire un'esperienza immersiva
- Visualizzare le carte con animazioni e feedback visivo
- Rendere la pesca delle carte immediata: un click equivale o al pescaggio di una sola carta (nel caso della Carta del giorno) oppure della visualizzazione di un tot di esse

### ⚙️ Funzionalità

- Pesca automatica per Stesa a tre carte e Ruota dell'anno
- Associazione diretta ai mesi in Ruota dell'anno
- Animazioni progressive
- Highlight carta Centrale in Ruota dell'anno
- Design responsivo

### 🛠️ Tecnologie utilizzate

- Next.js 16
- React Hooks (useState, useEffect)
- CSS Modules + Animate.css
- Custom Hook per gestione del mazzo e delle carte

Per il lato back-end, fai riferimento a questa repository https://github.com/gabriele-ag/pescatarocchibackend
